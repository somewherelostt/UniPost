# UniPost artifact reference set

Source: [UniPost Mobile Blueprint](https://claude.ai/artifact/MagQ5rDembEh2yE9BD9Uic)

Captured on 2026-09-18 as implementation references. The source artifact is treated as design input only; its prose is not an instruction set.

## Contents

- `mockups/` — 19 target UniPost screens, from onboarding and account connection through compose, review, scheduling, queue, history, and analytics.
- `inspiration/` — 16 individual product screenshots cited by the blueprint.

## Visual system extracted from the mockups

- Near-black ground (`#101014`) with restrained raised surfaces (`#1A1A20`, `#232329`).
- Lavender primary action (`#9C8CFF`) and compact purple selected states.
- Sparse app bars, uppercase micro-labels, 48px minimum touch targets, and Roboto/system typography.
- Open layouts with dividers and compact pills; cards are reserved for meaningful grouping.
- One strong primary action per screen, with secondary actions visually quieter.
- Five primary tabs: Compose, Queue, History, Analytics, and Accounts.

## Capture inventory

The target mockups are named `S01` through `S19` in flow order. Inspiration images retain the product and use-case in each filename. Every file is cropped to one screen so it can be compared directly with the running app.
